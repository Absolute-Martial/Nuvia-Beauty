# product/

Owner: Susank Shakya

<aside>
📁

**`docs/product/`** — the product-level documents that define *why* Nuvia Beauty exists, *what* it is, and *what ships first*.

</aside>

This folder holds the product narrative and scope, from the high-level vision down to the demo scripts. It is the entry point for understanding the problem, the ecosystem model, and the MVP boundary before reading the technical architecture. Each page is self-contained and kept in sync with its canonical version in the [Technical Papers](https://app.notion.com/p/Technical-Papers-36ff29d2a6b1807db908ff6401f784fe?pvs=21).

# How to read this folder

1. Start with [**concept-paper.md**](http://concept-paper.md) for the problem and vision.
2. Read [**white-paper.md**](http://white-paper.md) for the market and confidence-shopping rationale.
3. Read [**technical-proposal.md**](http://technical-proposal.md) for the approach, stack, and phasing.
4. Use [**mvp-boundary.md**](http://mvp-boundary.md) to see exactly what ships in the MVP.
5. Use [**demo-scenarios.md**](http://demo-scenarios.md) to run or rehearse a demo.

For architecture detail, continue to the `architecture/` folder; for delivery tracking, see `implementation-plan/`.
