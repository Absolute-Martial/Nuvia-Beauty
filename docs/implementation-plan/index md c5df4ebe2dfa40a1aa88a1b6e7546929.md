This is the central navigation hub for the Nuvia Beauty implementation plan. The plan is organized as a three-level hierarchy: **Implementation Plan (this index) → Phase → Sub-Phase**. Each phase page is an overview and navigation hub; each sub-phase is a dedicated, execution-ready page.

## How this hierarchy works

- **Index (this page):** roadmap, phase directory, execution order, and cross-references.
- **Phase pages:** overview, scope, roadmap positioning, and links to their sub-phases.
- **Sub-phase pages:** all detailed planning — objectives, requirements, tasks, deliverables, validation, acceptance/exit criteria, risks, rollout, and metrics.
