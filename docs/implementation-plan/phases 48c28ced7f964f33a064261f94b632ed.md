## Execution order

1. Run full backend/frontend validation. 2. Seed real demo products and mappings. 3. Deploy to staging/test. 4. Build seller consultation foundation (Phase 4). 5. Add Perfect Corp P0 in demo mode (Phase 5). 6. Prepare demo/push readiness (Phase 6). 7. Add personalized domain expansion (Phase 7). 8. Add customer self-scan & profile history (Phase 8). 9. Add Try-On Studio / Makeup VTO (Phase 9).
