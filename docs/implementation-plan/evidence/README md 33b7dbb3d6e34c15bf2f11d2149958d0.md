# Validation evidence record

Each verified delivery test is captured with the following fields:

- **Command executed**
- **Environment**
- **Result**
- **Screenshot / log output**
- **Failure notes**
- **Fix applied**
- **Retest result**

# Where to store it

Put each record in the matching subfolder: `backend-tests/`, `frontend-tests/`, `storage-tests/`, `security-tests/`, or `staging-verification/`.
