# 1. Purpose & scope

Perfect Corp provides the **P0 beauty analysis** that cold-starts Nuvia Beauty's intelligence before a custom model exists. This subfolder documents how that integration works: the analysis API, the deterministic demo-mode fallback, the stable internal contract, and the fallback behavior. The integration is **backend-only** and always degrades gracefully so demos and core flows never break ([ADR Pack](https://app.notion.com/p/ADR-Pack-36ff29d2a6b18108958af03b19f13a6e?pvs=21) ADR 0002).

# 2. Role in the system

P0 is the first link in the model strategy: cold-start with Perfect Corp, then accumulate consented data and seller corrections to train a custom model later (ADR 0008), always keeping a provider fallback. Perfect Corp results are normalized into the internal contract and never surfaced raw.

# 4. Principles

- **No provider credentials in any frontend** — keys live only in backend environment.
- **Private media only** — all media handled via private buckets + signed URLs, referenced by key.
- **Graceful degradation** — provider failures degrade to demo-mode, never to a broken UX.
- **Normalized output** — callers depend on the internal contract, not Perfect Corp's payload shape.

# 5. Configuration

```
AI_PROVIDER=perfect_corp        # or "demo" to force demo-mode
PERFECT_CORP_API_KEY=...        # backend-only, never NEXT_PUBLIC_*
PERFECT_CORP_ENDPOINT=...
AI_DEMO_MODE=false              # true forces deterministic demo-mode
```
