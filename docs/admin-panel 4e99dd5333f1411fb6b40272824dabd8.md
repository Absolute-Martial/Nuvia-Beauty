**`docs/admin-panel/`** — the internal operator app: flows, catalog management, runtime settings, and audit views.

</aside>

`admin-panel` (Next.js 15.5.18 / React 19.2.6, `:3002`, `@nuvia/admin-panel`) is the internal app for brand operators. It is a thin, role-gated client that talks only to `backend-engine`, holds no credentials, and edits only safe runtime values — every action is authorized by Policy and audit-logged ([ADR Pack](https://app.notion.com/p/ADR-Pack-36ff29d2a6b18108958af03b19f13a6e?pvs=21) ADR 0012).

# Principles

- Zero-trust: every action authorized by Policy (ADR 0012).
- Sensitive settings stay server-side; the panel edits only safe runtime values.
