# 1. Purpose & scope

`admin-panel` is the **internal operator app** for brand staff. It manages the product catalog, edits safe runtime settings, and provides audit visibility. Like the other frontends it is a thin client: it talks only to `backend-engine` over REST, holds no provider or storage credentials, and is gated by role-based authorization on every action.

# 4. Principles

- **Zero-trust** — every action authorized by a Policy (ADR 0012).
- **Server-side secrets** — the panel edits only safe runtime values; secrets and endpoints stay in environment.
- **No private media** — the panel never displays beauty media or full signed URLs.
- **Auditable** — destructive and sensitive actions are confirmed and audit-logged.
