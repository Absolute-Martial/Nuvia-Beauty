# storage/

Owner: Susank Shakya

<aside>
📁

**`docs/storage/`** — S3-compatible object storage: architecture, media lifecycle, private-bucket policy, and audit logging.

</aside>

This folder documents how Nuvia Beauty stores **public assets** and **private, consent-bound beauty media**. The governing rule across every page: raw facial images and analysis media are never publicly reachable, never stored in MySQL, and never handled with client-side credentials — only `backend-engine` mints short-lived signed URLs. These constraints come from [ADR Pack](https://app.notion.com/p/ADR-Pack-36ff29d2a6b18108958af03b19f13a6e?pvs=21) ADR 0003 and ADR 0009.

# Key facts

- Driver: `STORAGE_DRIVER=s3_compatible`, `S3_PROVIDER=minio_aistor`, `S3_USE_PATH_STYLE_ENDPOINT=true` (API `:9000`, console `:9001`).
- Adapter: Laravel Flysystem via `league/flysystem-aws-s3-v3`.
- Signed URL TTLs: **upload 15 min**, **download 60 min**.
- Buckets: `nuvia-public-assets` (public), `nuvia-private-beauty-inputs`, `nuvia-private-beauty-results`, `nuvia-private-calibration` (private).
