# Nuvia Beauty — Documentation

Documentation set for Nuvia Beauty, a multivendor AI beauty-commerce platform. See [docs/](../docs%204ad284736dcb4b45b39511e90c276caf.md) for the full folder map and conventions.

## How to navigate

- **00-overview/** — documentation entry point, glossary, naming, and conventions.
- **01-product/** — concept, white paper, personas, customer journeys, seller journeys, and product framing.
- **02-architecture/** — system design, reference architecture, ADRs, diagrams, service boundaries, data architecture, storage architecture, AI/provider architecture, security, and privacy.
- **03-decisions/** — ADR index and technical decision records.
- **04-implementation-plan/** — roadmap, phase index, phased delivery plan, sub-plans, status, risks, and evidence.
- **05-poc/** — feasibility specs and risky-assumption validation.
- **06-features/** — feature index, feature brainstorming, recommendation engine, seller consultation, product mapping, customer profile history, Try-On Studio, analytics, and insights.
- **07-validation/** — QA plans, acceptance criteria, launch readiness, demo scenarios, risk register, and safety/privacy checks.
- **08-operations/** — deployment, environment variables, monitoring, storage maintenance, and incident response.
- **backend-engine/**, **storefront/**, **admin-panel/**, **vendor-portal/** — per-app implementation docs.
