This folder is the entry point for the project's architecture decisions. Rather than scattering full records here, it keeps a **single enriched index** (`README.md`) that summarizes every decision and links to the canonical full-text records.

# How decisions are recorded

Each Architecture Decision Record documents **one decision** using a fixed convention so the reasoning stays reviewable over time:

- **Context** — the forces and constraints behind the decision.
- **Decision** — what was chosen.
- **Status** — `Proposed`, `Accepted`, `Superseded`, or `Deprecated`.
- **Consequences** — trade-offs, follow-on work, and mitigations.
