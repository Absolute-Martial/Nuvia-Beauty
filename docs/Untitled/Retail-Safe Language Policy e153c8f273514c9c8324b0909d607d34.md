# Retail-Safe Language Policy

Owner: Susank Shakya

<aside>
⚖️

Canonical language policy for all customer-facing beauty guidance — recommendation cards, explanation templates, seller scripts, and marketing copy. Enforced in templates and recommendation output. Resolves Risk Register ISS-22.

</aside>

# Why this exists

"No medical claims" alone is not enough. Beauty guidance touches skin type, concerns, ingredients, sensitivities, and patch-test language, which can easily drift into quasi-medical advice. This policy defines neutral, retail-safe wording so recommendations never read as diagnosis or treatment.

# Approved phrasing

- "may suit" / "may be a good fit for your profile"
- "seller review recommended"
- "predicted suitability" / "profile-based confidence"
- "product match explanation" / "recommendation reason"
- "observed response notes"
- "patch test suggested before use" (a neutral precaution, not medical advice)

# Required disclaimer

Every recommendation surface must carry: **"Cosmetic-fit guidance only — not medical advice."**

# Blocked language

- diagnoses / diagnosis
- cures / treats / heals
- "clinically proven" / "medically proven"
- "prevents disease" / "treats disease"
- any dermatological or clinical claim

# Enforcement

- Recommendation templates and explanation cards draw only from approved phrasing.
- A blocked-term checklist is applied to copy before release; flagged terms block publish.
- Seller-facing scripts use the same neutral phrasing.
- Adverse-reaction notes route only to avoid-tags and brand feedback — never health advice.
