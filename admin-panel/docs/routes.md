# Admin Panel Routes

## Admin routes

- `/login`
- dashboard index
- product management
- platform vendor or shop oversight
- user management
- support and message surfaces where enabled
- moderation views where enabled

## Hidden or restricted MVP areas

- General settings
- Payment settings
- SEO settings
- Company information
- FAQ editor
- Terms editor
- Shipping
- Withdrawals
- Shop transfer request
- Layout and page management

## Rule

Admin routes are private, must not be linked from the public storefront, and
must not remain the long-term home for vendor day-to-day workflows.
