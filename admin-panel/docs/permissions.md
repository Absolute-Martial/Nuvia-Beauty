# Admin Panel Permissions

## Admin

- Manage platform-level products
- Manage vendors and shops where enabled
- Manage users where enabled
- Moderate marketplace content
- View support and audit surfaces where implemented

## Vendor

Vendor users should not depend on this app long term. Vendor operations move to
the separate vendor dashboard tracked by
`../../plan/vendor-application-and-stack-upgrade.md`.

## Restricted

- Payment settings
- Withdrawals
- Payouts
- Commission settlement
- Shop transfer request
- Private backend secrets
