# Context, Scope, and Stakeholders

This document maps the systems and people that interact with our application.

---

## 🌐 System Context

Our application interacts with the following external systems and actors:
* **Users / Customers**: Interact with the Storefront to browse products and use features (e.g. Try-on).
* **Vendors**: Interact with the Vendor Portal to list products and fulfill orders.
* **Store Administrators**: Manage system configurations, users, and review logs via the Admin Panel.
* **External Integration 1**: (e.g. YouCam VTO API for virtual Try-On processing).
* **External Integration 2**: (e.g. Payment gateways like Stripe/Paypal).
