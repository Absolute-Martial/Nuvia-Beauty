# Functional Requirements

This document captures the functional capabilities of the system, mapped by user personas.

---

## 👥 Customer Requirements

| ID | Feature | Description | Priority |
| --- | --- | --- | --- |
| **FR-C-01** | Account Registration | Customers can register, verify email, and log in securely. | High |
| **FR-C-02** | Product Search / Filter | Customers can search catalog items by text, category, and price range. | High |
| **FR-C-03** | Virtual Try-On (VTO) | Customers can upload their selfie to overlay beauty products virtually. | High |

---

## 👥 Vendor Requirements

| ID | Feature | Description | Priority |
| --- | --- | --- | --- |
| **FR-V-01** | Vendor Onboarding | Users can apply to become store vendors and set up shop details. | Medium |
| **FR-V-02** | Product Listing | Vendors can add, edit, and delete products in their catalog. | High |

---

## 👥 Administrator Requirements

| ID | Feature | Description | Priority |
| --- | --- | --- | --- |
| **FR-A-01** | Vendor Moderation | Admins can approve, suspend, or block vendors. | High |
| **FR-A-02** | Analytics Dashboard | Admins can view aggregate metrics on revenue, VTO usage, and registrations. | Low |
